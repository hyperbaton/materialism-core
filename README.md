# Materialism Core

Auxiliary NeoForge mod for the [Materialism](https://github.com/hyperbaton) modpack (Minecraft 1.21.1).

Adds items and blocks that were removed or are missing from other mods but are needed for the modpack's tech progression.

## Planned Features

- **Galvanic Cell** — single-use battery block providing a small, non-replenishable amount of energy

## Building

```
./gradlew build
```

The built jar will be in `build/libs/`.
